# AI EVOLUTION GAME LAB

**مختبر يتعلّم من مشاريعك، ثم يصمّم ويبني ويشغّل ويختبر ويصلّح ألعاباً جديدة — ويقيس نفسه بصدق.**

A lab that learns from *your* projects, then designs, builds, runs, tests and
fixes new games — and measures itself honestly.

```
IMPORT → ANALYZE → UNDERSTAND → EXTRACT → STORE → RESEARCH → PLAN →
GENERATE → BUILD → RUN → TEST → EVALUATE → IMPROVE → LEARN → NEXT VERSION
```

لا يوجد `node_modules`. لا مكتبات خارجية. كل شيء يعمل بـ Node وحده، وبدون إنترنت.

Zero dependencies. Node only. Works offline.

---

## التشغيل السريع · Quick start

```bash
cd ai-evolution-game-lab

# 1) استورد مجلداً يحتوي مشاريعك (يكتشف كل مشروع تلقائياً)
node bin/lab.js import ~/MY_PROJECTS          # folder of many projects, or a .zip

# 2) اصنع لعبة جديدة: تصميم ← توليد ← تشغيل ← اختبار ← إصلاح ← حفظ
node bin/lab.js generate

# 3) افتح اللوحة
node bin/lab.js serve                          # http://127.0.0.1:7717
```

اللعبة الناتجة تُفتح مباشرة بالنقر على `index.html` — بلا خادم، بلا بناء، بلا تبعيات.

The generated game opens by double-clicking `index.html`: no server, no build
step, no dependencies.

## ماذا يفعل فعلاً · What it actually does

### 1. يستورد ويحلّل (Import + Analyze)

يكتشف المشاريع داخل مجلد واحد (`GAME_01/`, `GAME_02/`, `APP_01/`...) أو داخل ZIP،
وينسخها إلى مساحة العمل — **ملفاتك الأصلية لا تُمسّ أبداً**.

ثم يحلّل كل ملف تحليلاً حقيقياً:

| النوع | ما يُستخرج |
|---|---|
| JavaScript | مُحلِّل رموز كامل (تعليقات، نصوص، قوالب، regex) → دوال، أصناف، وراثة، رسم استدعاءات، واجهات المتصفح، أسلوب حلقة اللعبة، ثوابت الضبط |
| HTML | وسوم، سكربتات داخلية/خارجية، canvas، viewport، معالِجات inline |
| CSS | مُحدِّدات، متغيرات التصميم، flex/grid، media queries، keyframes، لوحة الألوان |
| GLB / glTF | قراءة ثنائية حقيقية: شبكات، مواد، عظام، مقاطع حركة ومدتها، صندوق إحاطة، اقتراحات تحسين |
| PNG | فك ضغط حقيقي (zlib + unfilter) → لوحة ألوان، كثافة، مناطق التخطيط |

ثم يحوّل ذلك إلى **مفاهيم مجرّدة** (49 كاشفاً) مع مصادرها ودرجة ثقتها — وليس نسخاً للكود.

### 2. يبني معرفة قابلة للمساءلة (Knowledge)

كل عنصر معرفي يحمل: المفهوم، الوصف، الأمثلة، **المشروع المصدر**، الثقة، المفاهيم المرتبطة،
الاستخدامات الناجحة والفاشلة.

- الثقة تعتمد على **عدد المشاريع المستقلة** لا على تكرار السطور.
- لا تتجاوز `0.9` إلا بعد أن ينتج المولّد كوداً عاملاً يعتمد عليها فعلاً.
- `Project Memory` (ذاكرة مشروع واحد) منفصلة تماماً عن `Global Knowledge` (المعرفة العامة).
- رسم معرفي بأوزان PMI يربط المفاهيم والأدوار والمكتبات.

### 3. يصمّم قبل أن يبرمج (Design Engine)

وثيقة تصميم كاملة قبل أي سطر كود: الفكرة ← الحلقة الأساسية ← هدف اللاعب ← التحكم ←
التقدّم ← منحنى الصعوبة ← العالم ← الواجهة ← البنية التقنية ← خطة التنفيذ.

**فضاء التصاميم: 73,304,064 تركيبة** عبر 13 بُعداً (النوع، الكاميرا، التحكم، العالم،
الهدف، التقدّم، الفيزياء، الأعداء، المكافآت، الأسلوب البصري، الواجهة، الصوت، **المُعدِّل**).

### 4. يمنع التكرار (Diversity + Novelty)

- **NOVELTY ENGINE**: يبحث في فضاء التصاميم عن النقطة **الأبعد** عن كل ما وُلِّد سابقاً
  (ترجيح عكسي للتشبّع + تقييم 48 مرشحاً)، لا مجرد عشوائية.
- **DIVERSITY ENGINE**: يقيس التشابه مقابل التصاميم السابقة؛ إذا تجاوز الحد يعيد التوليد
  بضغط جِدّة أعلى.
- **فحص أصالة الكود**: يقارن الكود المولَّد بالكود المستورد عبر بصمات n-gram ويرفض التشابه
  العالي — أي "نسخ بالخطأ" يُكتشف. القياس الفعلي في الألعاب المولّدة: **~2.5%**.

> التشابه هنا آلية تقنية لمنع التكرار، وليس حكماً على حقوق الملكية.

### 5. يولّد ألعاباً حقيقية (Generation)

ثمانية محرّكات لعب مختلفة فعلاً — لا محرك واحد بأعلام:

`arena` · `platformer` · `puzzle` · `racer` · `defense` · `runner` · `stealth` · `explorer3d`

كل مشروع مولَّد = 18–22 ملفاً منظّماً:

```
index.html · styles/main.css · manifest.json · README.md
src/engine/{core,math,input,entities,physics,collision,camera,ai,procgen,particles,render,ui,audio,save,three}.js
src/game/{config,world,rules,main}.js
```

ما يُولَّد ليس قالباً ثابتاً: نمط الحلقة، مُكامل الفيزياء، خوارزميات الذكاء، مولّدات العالم،
والثوابت — كلها تتغير حسب التصميم والسياسة والمعرفة المُتعلَّمة.

ضمانات حقيقية داخل المولّد:
- **الألغاز** تُولَّد بالعكس من حالة محلولة → كل لوحة قابلة للحل بالبناء.
- **المنصات** تُولَّد داخل مغلّف القفزة المحسوب من الجاذبية ثم يُتحقق من إمكانية العبور.
- **التسلل** يضع المخرج على بلاطة أثبت `flood fill` إمكانية الوصول إليها.
- **لوحة الألوان** تمرّ بفحص تباين WCAG (نص 7:1، عناصر اللعب 3.5:1) قبل الإصدار.

### 6. يشغّل ويختبر فعلاً (Sandbox + Test Agent)

صندوق تنفيذ داخل `node:vm` مع DOM وcanvas يسجّل الرسم ومصفوفة تحويل حقيقية وساعة افتراضية.
**لا `require`، لا `process`، لا شبكة** داخل الصندوق.

16 فحصاً بأدلة رقمية: التحميل، الإقلاع، البدء، **الاستجابة للإدخال**، الاستقرار،
**قفزات الإطارات**، الإيقاف عند إخفاء التبويب، الرسم، التخطيط البصري، **التباين**، الأداء،
الذاكرة/التدوير، **الحتمية**، الحفظ/التحميل، تخطيط الجوال، نظافة الكود، **إمكانية التقدّم**.

### 7. يصلّح نفسه (Automatic Debugging)

عند فشل فحص، يقرأ الخطأ ← يحدّد السبب ← يغيّر **السياسة أو التصميم** ← يعيد التوليد ← يعيد الاختبار.

مثال حقيقي من سجل التشغيل:

```
round 1: dt-spike  → {"loopStyle":"fixed-timestep-accumulator"}
         لأن: حلقة الدلتا المتغيرة سمحت بقفز الكيانات أثناء تجمّد الإطارات
round 2: dt-spike  → {"options":{"dtClamp":0.028}}
         لأن: قيد 1.5 ثانية ما زال يسمح بقفزة كبيرة
round 3: ship (score 0.967)
```

### 8. يتطوّر بقياس لا بادّعاء (Evolution)

- **Benchmark ثابت**: 8 مهام مثبّتة السمات بالكامل — المتغير الوحيد هو سياسة الوكيل.
- **Experiment Engine**: فرضية مكتوبة مسبقاً → متغيّران يختلفان في قرار واحد → قياس.
- **Version Manager**: الترقية تتطلب تحسناً **أكبر من هامش الضجيج** وبلا تراجع في أي مهمة؛
  وإلا تراجُع مسجَّل بالأدلة.
- بصمة المعرفة تُسجَّل مع كل قياس، ويحذّر النظام إذا تغيّرت المعرفة بين قياسين.

النظام يقول حرفياً عندما لا يتحسن شيء:

> *"No change beat the current policy by more than the noise margin; v1 remains active at benchmark score 0.9916."*

## الحدود الصادقة · The honesty boundary

هذه ليست تنازلات، بل جوهر التصميم:

| | الحالة |
|---|---|
| Knowledge learning (مفاهيم، معاملات، رسم معرفي) | ✅ منفَّذ |
| Memory learning (ذاكرة مشروع + معرفة عامة) | ✅ منفَّذ |
| Workflow learning (سياسات الوكيل بقياس benchmark) | ✅ منفَّذ |
| Retrieval (استرجاع معجمي) | ✅ منفَّذ |
| **Fine-tuning / Continued training** | ⚠️ **واجهة فقط** — يحتاج خلفية GPU |

- **تحسين الوكيل ≠ تدريب النموذج.** لا أوزان تتغير هنا، والنظام لا يدّعي ذلك أبداً.
- لا يُقال "صار أذكى". يُقال: `+X.XX نقطة على benchmark من 8 مهام`.
- بدون نموذج رؤية مُهيّأ، تحليل الصور **بنيوي فقط** (أبعاد، ألوان، مناطق) ويُصرَّح بذلك في الناتج.
- بناء 3D لا يمكن التحقق منه في الصندوق (لا WebGL) — يُفحص ثابتاً ويُقال ذلك صراحةً.
- المتصفح وحده لا يواصل التنفيذ بعد إغلاق الصفحة؛ المهام الطويلة تعمل في الخادم.

## الأمان والتراخيص · Security & licensing

- **نطاق مغلق**: كل عملية ملفات تمر عبر `Scope` — لا قراءة ولا كتابة خارج مساحة العمل
  والمجلدات الممنوحة صراحةً. لا يوجد علم تجاوز.
- **الشبكة مغلقة افتراضياً**، والبحث مقصور على قائمة مصادر رسمية (MDN, W3C, WHATWG, Khronos, three.js...).
- **لا مفاتيح إلا مفاتيحك**: من إعداداتك أو من متغير بيئة. النظام لا يبحث عن مفاتيح أحد ولا يستخدمها.
- **بلا تدمير**: النسخ لا التعديل، مع لقطات ونُسخ وتراجع.
- **التراخيص**: كشف تلقائي (LICENSE, package.json, SPDX). ما لا يُعرف يُسجَّل `LICENSE_UNKNOWN`
  ولا يُعتبر صالحاً للاستخدام التجاري تلقائياً.
- الألعاب المولَّدة **لا تحزم أي أصول خارجية**: كل الرسوم والأصوات تُنتَج وقت التشغيل من الكود.

## الأوامر · Commands

```bash
lab serve [--port 7717] [--host 127.0.0.1]   # اللوحة + API + بث الأحداث
lab import <path> [--no-analyze]             # مجلد مشاريع أو ZIP
lab learn [--reanalyze]                      # تحليل كل ما استُورد
lab knowledge                                # طباعة قاعدة المعرفة
lab design  [--genre X] [--twist Y]          # وثيقة تصميم فقط
lab generate [--genre X] [--rounds 3]        # تصميم ← بناء ← تشغيل ← اختبار ← إصلاح
lab test [generatedId]                       # إعادة تشغيل وكيل الاختبار
lab benchmark                                # قياس الإصدار الحالي
lab evolve [--cycles 3]                      # دورات تحسين ذاتي
lab versions | lab rollback <v>              # تاريخ الإصدارات والتراجع
lab research "<question>"                    # توثيق رسمي مع مقارنة مصادر
lab dataset [--name X]                       # بناء مجموعة بيانات
lab export <project|knowledge|memory|evaluation|datasets|logs>
lab status
```
