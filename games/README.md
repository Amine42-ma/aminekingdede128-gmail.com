# 🎮 مجنون ألعاب · Majnoon Games

**ملف HTML واحد** يحتوي على **٢٠٠ لعبة أصلية مختلفة** — لا لعبة تشبه الأخرى.
لا إنترنت، لا إعلانات، لا تتبّع، ولا أي ملف خارجي. افتح `index.html` وابدأ اللعب.

---

## ما الذي يجعل هذا التطبيق مختلفاً

- **كل لعبة مكتوبة يدوياً** بمنطقها الخاص — ليست نسخاً معادة بألوان مختلفة.
- **٢٢ تصنيفاً**: أكشن، آركيد، ألغاز، تفكير، مهارة، سرعة، ذاكرة، فيزياء، سباق، إطلاق نار،
  رياضة، ألواح، حظّ وبطاقات، كلمات، أرقام، موسيقى، **مضحكة**، **مزعجة عمداً**،
  **عصبية**، **أفكار غير موجودة**، لاعبان، عائلية.
- **واجهة عربية كاملة (RTL)** بتصميم شبيه بمنصّات الألعاب الكبرى: بحث، تصنيفات،
  مفضّلة، «لعبت مؤخراً»، أرقام قياسية، صفحة لعب بملء الشاشة.
- **يعمل باللمس والفأرة ولوحة المفاتيح** — ولوحة تحكّم افتراضية على الجوال.
- **صوت مولّد بالكامل** عبر Web Audio (لا ملفات صوتية): طلقات، عملات، انفجارات،
  وحتى… أصوات أخرى لا تليق بذكرها في ملف README.

## التشغيل

```bash
# افتح الملف مباشرة
xdg-open games/index.html      # أو انقر عليه مرّتين

# أو عبر خادم محلي
python3 -m http.server 8000
# ثم: http://localhost:8000/games/index.html
```

الملف يعمل من `file://` بلا أي مشكلة — لا يحتاج خادماً ولا اتصالاً.

## البنية والتطوير

الملف النهائي `index.html` **مولَّد** من مصادر مقسّمة:

```
games/
├── index.html              ← الناتج النهائي (ملف واحد مكتفٍ بذاته)
├── build.sh                ← سكربت البناء (cat بسيط، بلا أي اعتمادات)
└── src/
    ├── head.html           ← الترويسة والوسوم
    ├── style.css           ← كل الأنماط (RTL، داكن، متجاوب)
    ├── body.html           ← هيكل الواجهة
    ├── engine.js           ← المحرّك: حلقة الرسم، الإدخال، الصوت، الجسيمات، الأدوات
    ├── app.js              ← الواجهة: البحث، التصنيفات، التوجيه، الحفظ المحلي
    └── games/
        ├── 01-arcade.js … 14-classics.js   ← الألعاب مجمّعة حسب النوع
```

لإعادة البناء بعد أي تعديل:

```bash
cd games && ./build.sh
```

### كيف تضيف لعبة جديدة

كل لعبة تُسجَّل بدالة واحدة داخل أي ملف في `src/games/`:

```js
G({
  id:'my-game', t:'اسم اللعبة', c:'arcade', e:'🎲',
  tags:['وسم'], d:'وصف قصير يظهر في صفحة اللعبة.',
  how:'طريقة التحكم',
  make:function(E){            // E = محرّك اللعبة
    var x = 400;
    return {
      update:function(dt){ x += E.kx() * 200 * dt; },
      draw:function(c){ E.bg('#101020'); E.o(x, 300, 20, '#9dff3d'); },
      down:function(px,py){},   // لمسة/نقرة
      key:function(k,down){}    // مفتاح
    };
  }
});
```

أهم ما يوفّره المحرّك `E`:

| المجال | الدوال |
|---|---|
| الرسم | `bg` `sky` `r` `rr` `o` `ring` `arc` `ln` `poly` `tx` `spr` `emo` `grid` `hud` `hudL` |
| الإدخال | `k(key)` `kx()` `ky()` `tap(key)` · `E.m` = {x, y, down} |
| الأدوات | `rnd` `ri` `pick` `cl` `lerp` `dist` `hit` `hitc` |
| التأثيرات | `s('coin')` `note(freq)` `shake(n)` `burst(x,y,color,n)` `rise` |
| الحالة | `add(n)` `setScore(n)` `over(title,sub)` `won(title,sub)` |

مساحة اللوحة المنطقية دائماً **٨٠٠×٦٠٠** وتُقاس تلقائياً على أي شاشة.

## الاختبار

كل الألعاب تمرّ باختبار آلي (Playwright) يفتح كل لعبة، يضخّ إدخالاً عشوائياً
لمئات الإطارات، ويعيد التشغيل عند انتهائها — ويرصد أي خطأ في وحدة التحكّم:

```bash
node test.js     # ٠ أخطاء في ٢٠٠ لعبة
```

## التوافق

يعمل على Chrome و Edge و Firefox و Safari (سطح المكتب والجوال).
